Case Agent - 案例智能体
====================
基于AI大模型的对话式案例助手

启动方式：
  1. 双击 start.bat
  2. 打开浏览器访问 http://localhost:3900
  3. 局域网内其他设备访问 http://[本机IP]:3900

前置要求：
  - Node.js v18+
  - 无需安装数据库，纯内存运行

功能：
  - 上传案例文档（.docx/.pdf/.txt）
  - 决策情报顾问：基于案例的政策分析
  - 利益相关方博弈：多角色模拟对话
  - 案例推演：全流程推演 + 决策弹窗 + 总结报告
  - 侧边会话管理，多对话独立存储

技术栈：
  - Node.js + Express
  - 商汤日日新 API (deepseek-v4-flash)
  - 纯前端 SPA (无框架依赖)
